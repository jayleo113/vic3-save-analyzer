# v0.4 目标：历史对照与完整世界链

v0.4 的核心目标是把 v0.3 的“单存档国家档案”和“多存档差异对照”升级为可连续追踪的世界历史链。

## 总目标

- 以同一局游戏的多个存档为输入，生成完整世界时间线。
- 明确展示国家、疆域、附属关系、市场、条约、战争、政治运动和经济结构的变化。
- 区分直接记录、快照差异和无法确定的过程，不编造缺失历史。
- 保持 v0.3 已有的正确性、缓存复用和桌面 Markdown 体验。

## 一、历史组与战役识别

- 增加“历史组”管理：用户可以把多个存档加入同一局游戏。
- 每个历史组记录名称、存档列表、游戏日期、源文件 SHA-256 和生成时间。
- 不自动混合不同战役；同名国家、同日期或同标签都不能单独作为连续依据。
- 支持重新扫描历史组，发现新增存档后增量补入。

## 二、完整世界链

- 从每个存档提取全世界国家、州、市场、条约、战争、军队、人口与经济状态。
- 建立统一时间轴，按游戏日期串联每个世界截面。
- 每个时间点保留来源存档、内部日期和完整校验。
- 对国家改名、消失、独立、吞并、附属关系变化做显式记录。

## 三、疆域与国家变化

- 追踪州和战略区域的归属变化。
- 标注新增国家、消失国家、复国、附属国变化、宗主国变化。
- 对领土变化只写“两个时间点之间发生了变化”；只有存档提供战争或条约证据时，才关联可能原因。
- 支持按国家、地区、时间段筛选变化。

## 四、战争与外交链

- 串联战争、外交博弈、战争目标、参战方、战斗、伤亡和战争成本。
- 展示战争从出现到结束的存档时间点。
- 对和平条约、条约条款、市场准入、附庸化、割地等外交结果做关联。
- 缺少参战方或战斗记录时明确标注数据不足。

## 五、社会经济链

- 对每个主要国家追踪 GDP、人口、生活水平、识字率、公司、建筑结构、职业结构、文化宗教变化。
- 支持输出国家长期变化表和世界排名变化。
- 对市场成员、商品、贸易容量和市场中心变化做时间线。

## 六、报告输出

- 新增“世界历史链报告.md”。
- 新增“国家历史档案.md”，聚焦单个国家在多个时间点的发展。
- 新增“战争历史档案.md”，聚焦每场战争的过程和相关证据。
- 桌面资料库继续只放 Markdown，数据缓存继续留在 F 盘。

## 七、性能与缓存

- 历史组以单个存档数据包为基础，不重复解析已经建库的存档。
- 时间线对照直接读取 SQLite 数据包，避免重扫 `.v3`。
- 增加历史组索引和差异缓存，重复生成历史报告时只处理新增或变化的快照。
- Rust 可继续作为低层扫描加速路线，但 v0.4 的主目标是历史链完整性，不以 Rust 重写为前提。

## 八、验收标准

- 至少用一组 5 个以上同局存档验证历史组。
- 至少覆盖一个发生战争、附属关系变化或疆域变化的时间段。
- 报告能列出每个时间点的来源、日期和校验。
- 缺失表、缺失战争细节、无法确认因果时必须明确标注。
- 同一历史组重复生成报告应明显快于首次生成。

## 不属于 v0.4 的目标

- 不做玩法建议和主观战略推荐。
- 不自动恢复存档已经丢弃的全部历史事件。
- 不把不同战役自动合并成一条历史。
- 不强制用户安装 Rust 或外部数据库服务。
